A [make.fun](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) bounty entry: send exactly one emoji, the one most likely to make a stranger smile.

## The entry

**🤗 Hugging Face (U+1F917)** — a warm, open-armed smile offered to a stranger.

Why this emoji, scored against the judge's brief (most important first):

1. **Plainly aims to warm a stranger** — an open-armed hug is warmth offered, not just a face.
2. **Warm at first glance** — kind, friendly and gently funny with no context needed.
3. **Universal** — a stranger of any age or background reads a hug the same way; no irony or in-joke.
4. **Chosen, not default** — picked for the moment instead of the first smiley that comes to mind, while staying instantly readable.
5. **Right for a stranger** — friendly warmth with no intimacy, sarcasm or flirtation.

## How to run

```sh
python3 main.py
```

The program writes exactly one emoji, and nothing else, to `/output/entry.txt`. Pure Python standard library, deterministic: every run produces the same single character.

## Prize

$5 total, split over the top 10 places (1st $1.54). A judge model compares emojis two at a time and picks the warmer; the emoji that wins the most comparisons takes first place.
